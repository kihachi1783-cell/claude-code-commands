1. 会話・セッション管理 11

コマンド種別説明別名・備考
/clear [name]組み込みコンテキストを空にして新しい会話を開始。名前を付けると /resume 一覧で前の会話のラベルになる別名: /reset, /new
/compact [instructions]組み込み会話を要約してコンテキストを空ける。要約の重点を指示できる
/resume [session]組み込みID・名前で会話を再開、または選択画面を開く別名: /continue
/rename [name]組み込みセッション名を変更。省略すると会話内容から自動命名
/branch [name]組み込み会話をその時点で分岐し、元の会話を残したまま別方向を試す
/rewind組み込み会話やコードを以前の時点に巻き戻す（チェックポイント）別名: /checkpoint, /undo
/export [filename]組み込み会話をテキストで書き出す
/copy [N]組み込み直近（N番目）のClaudeの返答をクリップボードへコピー
/recap組み込み現在のセッションを1行で要約
/btw [question]組み込み会話に追加せず、ちょっとした横道の質問をする
/exit組み込みCLIを終了（バックグラウンドセッションではデタッチ）別名: /quit

コマンド種別説明別名・備考

/output-style [style]組み込み出力スタイルの一覧表示・切り替えv2.1.269+
/goal [condition|clear]組み込み条件を達成するまでClaudeが複数ターン作業を続ける「ゴール」を設定
/plan [description]組み込みプロンプトから直接プランモードに入る

/runスキルプロジェクトのアプリを起動・操作して変更が動くことを確認
/verifyスキルアプリをビルド・実行して変更が意図通りか確認
/run-skill-generatorスキル/run と /verify 用にプロジェクト固有の起動手順スキルを生成
/claude-api [subcommand]スキルClaude API / Managed Agents のリファレンスを読み込む（migrate, upgrade など）anthropic SDK import 時は自動

起動コマンド（ターミナルで実行）

コマンド説明
claude対話セッションを開始
claude "query"初期プロンプト付きで対話セッションを開始
claude -p "query"非対話(SDK)で実行して終了
cat file | claude -p "query"パイプで渡した内容を処理
claude -c現在のディレクトリの直近の会話を継続
claude -r "<session>" "query"セッションID/名前を指定して再開
claude update最新バージョンに更新
claude install [version]ネイティブバイナリをインストール（stable / latest / バージョン指定）
claude gateway --config gateway.yaml管理者向けセルフホストのゲートウェイを起動

主な起動フラグ

フラグ説明
--modelセッションのモデルを指定（sonnet / opus / haiku / fable や正式名）
--print, -p対話せず結果だけ出力（非対話モード）
--continue, -c / --resume, -r会話の継続 / 再開
--name, -nセッションの表示名を設定
--fork-session再開時に新しいセッションIDを作る
--permission-mode権限モードを指定（plan, auto など）
--dangerously-skip-permissions権限確認をすべてスキップ（bypassPermissions と同じ。要注意）
--add-dir作業ディレクトリを追加
--output-format / --input-format非対話モードの出力 / 入力形式（text, json, stream-json）
--json-schemaJSON Schema に合う検証済みJSON出力を得る（-p のみ）
--max-turnsエージェントのターン数上限（-p のみ）
--system-prompt / --system-prompt-fileシステムプロンプト全体を置き換える
--append-system-prompt / --append-system-prompt-file既定のシステムプロンプトに追記
--mcp-config / --strict-mcp-configMCP設定の読み込み / 指定した設定のみ使用
--plugin-dir / --plugin-urlこのセッション限定でプラグインを読み込む
--settings / --setting-sources設定ファイルの指定 / 読み込む設定元の指定
--agentこのセッションで使うエージェントを指定
--bareフック・スキル・MCP・CLAUDE.md の自動検出を省いた最小起動
--chrome / --no-chromeChrome連携のオン/オフ
--ideIDEが1つだけなら起動時に自動接続
--worktree, -w / --tmuxgit worktree で作業 / そのtmuxセッションを作成
--remote-control, --rcclaude.ai などから操作できる状態で起動
--cloudクラウドセッションを作成（--remote は旧名）
--teleportクラウドセッションをローカル端末で再開
--from-pr特定のPRに紐づくセッションを選択
--session-idUUID形式でセッションIDを指定
--no-session-persistenceセッションを保存しない（-p のみ）
--debug / --debug-file / --verboseデバッグ / ログ出力先 / 詳細ログ
--disable-slash-commandsスキルとコマンドをすべて無効化
--version, -vバージョンを表示

該当するコマンドがありません。
